# 🎓 Smart Classroom Attendance System (Face Recognition)

A simple web-based attendance system that uses face recognition concepts (demo mode) to mark student attendance automatically.

## 🚀 Features

- 📷 Live camera feed using webcam
- 🧠 Face recognition model integration (face-api.js)
- 📋 Automatic attendance table generation
- ✅ Randomized demo attendance marking
- 🎨 Clean and modern UI design

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- face-api.js (for face detection & recognition)

   ```bash

   ```

2. Open the project folder:
   ```bash
   cd my-first-website
   ```

3. Open `index.html` in your browser  
   (Double click OR right click → Open with browser)

---

## 📸 How It Works

- The app accesses your webcam
- Loads face detection models using `face-api.js`
- Displays student list with default status **Absent**
- When you click **Start Attendance**:
  - (Demo Mode) Random students are marked **Present**

---

## ⚠️ Note

- This is a **demo project**
- Real face recognition requires:
  - Training face data
  - Matching real face descriptors
  - Backend/database integration
